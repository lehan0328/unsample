# CLI Reference

## Commands

### `unsample debug <url>`

Send a debug request to the given URL. Unsample signs an HMAC token, injects it as W3C baggage, sends the request, and polls the trace backend for the complete trace.

```bash
# GET request
unsample debug 'https://api.myapp.com/users/123'

# POST with curl syntax
unsample debug --curl 'curl -X POST -H "Content-Type: application/json" -d "{}" https://api.myapp.com/checkout'
```

**Flags:**

| Flag | Default | Description |
|---|---|---|
| `--config`, `-c` | (auto-discovered) | Config file path |
| `--curl` | — | Parse the argument as a curl command |

---

### `unsample init`

Generate the configuration files needed to run Unsample locally. Creates a `.unsample/` directory with a generated secret, Docker Compose file, and OTel Collector/Tempo/Grafana configs.

```bash
unsample init
```

**Flags:**

| Flag | Default | Description |
|---|---|---|
| `--dir` | `.unsample` | Output directory for generated files |
| `--force` | `false` | Overwrite existing files |

---

### `unsample completion <shell>`

Generate shell completion scripts for bash, zsh, fish, or powershell.

```bash
# zsh (add to ~/.zshrc for persistence)
source <(unsample completion zsh)

# bash
source <(unsample completion bash)

# fish
unsample completion fish | source
```

---

### `unsample version`

Print the version of unsample.

```bash
unsample version
```

---

## Environment Variables

| Variable | Description |
|---|---|
| `UNSAMPLE_SECRET` | HMAC shared secret (overrides config file) |
| `UNSAMPLE_BACKEND_ENDPOINT` | Trace backend URL for polling |
| `UNSAMPLE_VIEWER_URL` | Trace viewer base URL |

Environment variables override config file values.

## Config File

The CLI auto-discovers config files in this order:

1. `--config` flag (explicit path)
2. Environment variables (highest priority for individual values)
3. `~/.unsample/config.yaml` (user-level)
4. `.unsample/config.yaml` (project-local, created by `unsample init`)
5. Built-in defaults

```yaml
# .unsample/config.yaml (generated by unsample init)
secret: "auto-generated-hex-string"
backend:
  type: tempo
  endpoint: http://localhost:3200
viewer:
  type: grafana
  url: http://localhost:3000
```

After running `unsample init`, you can immediately use `unsample debug <url>` without exporting any environment variables — the CLI reads the secret from `.unsample/config.yaml` automatically.
