# Unsample — Project Rules

## Architecture
- **3 components**: CLI (`cmd/unsample/`), SDK interceptor (`sdk/go/`), Collector processor (`internal/collector/`)
- **`internal/`**: Private packages — token system, CLI logic, collector processor, trace poller
- **`sdk/go/`**: Public Go SDK — HTTP middleware, gRPC interceptor, token verification
- **`cmd/unsample/`**: CLI binary entry point
- **`examples/demo-app/`**: Multi-service demo application
- **`docker/`**: Docker Compose + Collector config for local dev

## Go Code Standards
- **No `any` or `interface{}`** — use concrete types
- **All exported functions must have doc comments**
- **Error wrapping**: use `fmt.Errorf("context: %w", err)` — always wrap with context
- **Test files**: co-located with source (e.g., `hmac_test.go` next to `hmac.go`)
- **Benchmarks**: include for any hot-path code (token verification, span routing)

## Safety Guardrails (From Sherlog Production Incidents)
These are non-negotiable requirements derived from real production incidents:

1. **HMAC-signed tokens** — never trust bare `debug=true`. Token format: `<trace_id>:<timestamp>:<hmac_base64url>`
2. **Time-bound tokens** — 2h default expiry, reject future tokens (1 min clock skew)
3. **O(1) hot-path** — debug flag check must be zero-allocation when debug is OFF
4. **Never retry on throttle** — if Collector rate-limits, SDK drops immediately (return nil)
5. **Stateless per-span routing** — NEVER use `groupbytrace` in Collector (causes OOM)
6. **Payload truncation** — 64KB max body, depth 10, 4KB strings — enforced at SDK before export
7. **Separate debug backend** — route debug traces to isolated storage with 7-day TTL
8. **Trace polling before deep link** — CLI must poll backend before outputting link (avoid 404)

## Token System (`internal/token/`)
- Token format: `<trace_id>:<unix_timestamp>:<hmac_base64url>`
- Generated by CLI, verified by SDK interceptor AND Collector processor
- Shared secret via `UNSAMPLE_SECRET` env var or `~/.unsample/config.yaml`
- Uses `crypto/hmac` + `crypto/sha256` with constant-time comparison

## Collector Processor (`internal/collector/`)
- Stateless span router — iterates `pdata.Traces`, checks `span.attributes["debug.trace"]`
- Routes debug spans to debug exporter, production spans to production exporter
- Rate limiter: token bucket, max N debug traces per minute
- **Critical**: SDK copies `baggage` → span attribute because Collector never sees transport headers

## CLI Output Pattern
- Display HTTP response first (did the bug reproduce?)
- Spinner while polling for trace (avoid "Trace Not Found" 404)
- Deep link to Jaeger/Tempo when trace is ready
- Lightweight inline summary (service name, duration, status — NOT a terminal waterfall)

## Dependencies
- `github.com/spf13/cobra` — CLI framework
- OTel SDK + Collector SDK (when implementing processor)
- No unnecessary dependencies — keep the binary small
